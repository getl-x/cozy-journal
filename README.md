# Cozy Journal 手账主题

Cozy Journal 是由“GetL-X”制作的一款温馨、可爱、带纸张触感的经典 WordPress 博客主题。它不依赖外部字体、图片或 JavaScript 库，安装后即可使用。v1.3.2 是前台手账写作功能的安全修复版，保留文章作者、原发布时间、定时状态和密码保护，并加强了点击劫持、分类法权限和自定义角色兼容性。

## 安装或升级

1. 进入 WordPress 后台的「外观 → 主题 → 安装主题 → 上传主题」。
2. 上传带版本号的主题 ZIP。
3. 如果 WordPress 提示目标主题已存在，确认使用新版本替换主题文件。
4. 安装完成后启用 Cozy Journal。
5. 点击后台左侧的「手账主题设置」，检查前台写作和其他主题选项。

升级只替换主题程序文件，不会删除 WordPress 数据库中的文章、页面、媒体、评论或主题设置。通过服务器文件管理器安装时，也可以把主题内部的 `cozy-journal-wordpress-theme` 文件夹放到 `wp-content/themes/`。

## 在网页中直接写文章

启用主题后，默认访问站点的 `/write/`，例如：

```text
https://你的站点地址/write/
```

如果站点没有启用固定链接，写作台会自动使用：

```text
https://你的站点地址/?cozy_journal_write=1
```

可以在「手账主题设置 → 前台写作 → 写作页面路径」中把 `write` 改成其他路径。例如填写 `journal-write` 后，写作地址会变为：

```text
https://你的站点地址/journal-write/
```

路径只填写一段英文小写、数字、短横线或下划线，不要填写域名和斜杠，也不要与已有页面、文章、文章类型、分类法、WordPress 系统地址或插件固定入口重复。保存、导入备份或恢复默认路径前会先检查冲突；验证通过后所有写作入口会自动更新，旧写作路径不再打开写作台。

已登录且具有文章新建权限的用户，还可以从以下入口打开新文章写作台：

- 网站页头的“写文章”按钮。
- WordPress 顶部管理工具栏的“写手账”。
- 后台「手账主题设置」欢迎页的“打开写作台”。

写作台支持：

- WordPress 可视化编辑器和文本模式。
- 插入媒体库中的图片，也可以上传新媒体。
- 标题、正文、摘要、分类、标签和评论开关。
- 上传、替换或移除特色图片。
- 保存草稿、保存文章修改、预览、发布或提交审核。
- 标题或正文遗漏时在提交前提示并聚焦对应字段。
- 校验或保存失败后恢复刚才填写的文字与选项；本地图片文件需要按浏览器安全要求重新选择。
- 显示当前账号最近编辑的 6 篇文章。
- 分别提醒文字与特色图片尚未保存的状态，并在离开页面前进行确认。

## 权限规则

- 未登录用户访问 `/write/` 时会立即跳转到站点 `/404/`，不会显示写作台或登录表单。
- 新建文章使用内置文章类型的 `create_posts` 能力；编辑已有文章另行检查该文章的 `edit_post` 对象级能力。
- 作者、编辑和管理员可以使用写作台；实际权限仍以 WordPress 角色能力为准。
- 用户只能编辑 WordPress 允许其编辑的文章。
- 编辑已有文章时会认领并定时刷新 WordPress 文章锁；被其他用户锁定时不会覆盖对方内容。
- 有内置文章类型 `publish_posts` 能力的用户可以直接发布；没有该能力的用户只能提交审核。
- 分类和标签分别遵循对应分类法的 `assign_terms` 能力，无权时不显示或更改相应内容。
- 媒体按钮和特色图片上传还要求账号具有 `upload_files` 权限。
- 写作台响应会禁止浏览器缓存并标记为不供搜索引擎索引。

## 自动保存与预览

- 自动保存默认每 30 秒运行一次，也可以改为 60 秒、2 分钟或完全关闭。
- 自动保存只处理新文章、草稿和待审核文章。
- 只有标题、正文、摘要、分类、标签或评论设置发生变化时才触发自动保存；单独选择、替换或移除特色图片必须手动保存。
- 自动保存请求返回前如果又有新输入，旧响应不会清除未保存状态，并会在短暂等待后继续保存新版本。
- 已发布、私密或定时文章不会自动保存，必须点击“保存文章修改”。
- 新文章、草稿和待审核文章使用“保存并预览这一页”时，会先保存当前内容，再在新标签页打开预览。
- 已发布、私密或定时文章的查看按钮只打开当前已经保存的版本，不会把输入框里尚未确认的修改写到线上；需要先保存修改，再打开查看。
- 标签可以使用中文逗号、英文逗号、顿号或分号分隔。

## 前台写作设置

在后台「手账主题设置 → 前台写作」或「外观 → 自定义 → 手账主题设置 → 前台写作」中可以调整：

- 启用或关闭前台手账写作台。
- 写作页面路径，默认是 `write`。
- 是否在网站页头显示“写文章”。
- 是否允许从写作台上传特色图片。
- 草稿自动保存间隔。
- 写作台顶部寄语。

关闭写作台后，当前设置的写作路径会返回 404，前台入口和自动保存接口也会停止工作。

## 其他可调整内容

主题选项主要位于后台左侧的「手账主题设置」。独立设置中心带分区导航、顶部/底部保存按钮、分区重置、全部重置和设置备份恢复；「外观 → 自定义 → 手账主题设置」仍然保留，可用于实时预览。

- 初始设置：首页欢迎卡与日期开关、静态首页最新文章数量。
- 首页欢迎卡：小标签、标题、说明、按钮文字与链接。
- 颜色与字体：主色、点缀色、纸张色、卡片色、文字色、标题/正文字体以及卡片圆角。
- 文章与布局：双列拼贴或单列日记、侧栏、特色图片与摘要开关。
- 纸胶带与贴纸：装饰开关，以及花草、宅家、甜点、星月四套贴纸。
- 页脚小纸条：页脚寄语与年份/站点名开关。
- 备份与恢复：导出或导入 JSON 设置文件，以及安全恢复主题默认值。

站点名称、站点副标题和 Logo 仍在 WordPress 自带的「站点身份」区域设置。导航菜单在「外观 → 菜单」中分别分配到“主导航”和“页脚导航”。

## 推荐的首次设置

1. 在「设置 → 阅读」中选择“您的主页显示：您的最新文章”；也可以使用静态首页，并在主题的“初始设置”中调整最新文章数量。
2. 在「设置 → 固定链接」中选择文章名结构，保存后访问默认的 `/write/`，或使用主题设置中的自定义路径。
3. 在「手账主题设置 → 前台写作」中确认写作台和页头入口已启用。
4. 为文章设置特色图片，让文章卡片呈现拍立得拼贴效果。
5. 在「外观 → 小工具」中给“手账侧栏”添加作者简介、搜索、分类、标签或近期文章。

## 回退到历史版本

项目发布目录保留 v1.3.1、v1.3.0、v1.2.1 和 v1.1.0 安装包。v1.3.2 包含写作台安全修复，不建议在生产站点回退到 v1.3.1 或更早版本。回退只替换主题代码：

- 使用 v1.3.2 写作台创建或修改的文章仍保存在 WordPress 数据库中。
- 已上传到媒体库的图片仍会保留。
- 切回 v1.3.1 后，不再包含文章隐藏字段保留、防点击劫持和分类法权限修复。
- 切回 v1.3.0 后，写作路径功能仍然存在，但不会包含 v1.3.1 的表单恢复、竞态保护和文章锁修复。
- 切回 v1.2.1 后，写作入口恢复为固定的 `/write/`。
- 切回 v1.1.0 后，前台 `/write/` 写作台和相关入口会消失。
- 回退前仍建议使用主机快照或 WordPress 备份插件备份站点数据库与 `wp-content`。

## 主题特性

- 响应式布局，适配桌面、平板和手机。
- 支持自定义 Logo、菜单、背景、特色图片、评论与小工具。
- 支持 Gutenberg 宽幅/全宽区块、编辑器样式和主题色板。
- 带文章、页面、归档、搜索、404、评论和无内容状态模板。
- 键盘焦点、跳转正文链接、导航 ARIA 属性和减少动态效果支持。
- 打印文章时自动隐藏导航、侧栏和装饰。
- 不加载远程资源，适合国内网络环境。
- 带独立后台主题设置中心，并与 WordPress 自定义器同步主题设置。
- 支持设置导出、导入、分区重置与全部重置。

## 文件结构

```text
cozy-journal-wordpress-theme/
├─ assets/css/              后台设置中心与前台写作台样式
├─ assets/js/               导航、自定义器、后台设置与写作台交互
├─ inc/                     自定义器、设置中心、前台写作与模板标签
├─ template-parts/          文章卡片、正文和空状态
├─ 404.php                  404 页面
├─ archive.php              归档页
├─ comments.php             评论区
├─ footer.php               页脚
├─ front-page.php           首页
├─ functions.php            主题功能入口
├─ header.php               页头与导航
├─ index.php                默认文章列表
├─ page.php                 独立页面
├─ search.php               搜索结果
├─ searchform.php           搜索表单
├─ sidebar.php              小工具侧栏
├─ single.php               文章页
├─ style.css                主题信息与完整样式
├─ theme.json               区块编辑器配置
├─ writing-desk.php         前台手账写作台模板
└─ CHANGELOG.md             版本更新记录
```
