# Cozy Journal 手账主题

Cozy Journal 是由“GetL-X”制作的一款温馨、可爱、带纸张触感的经典 WordPress 博客主题。它不依赖外部字体、图片或 JavaScript 库，安装后即可使用，也适合继续做子主题或二次开发。

## 安装

1. 将整个 `cozy-journal-wordpress-theme` 文件夹压缩为 ZIP。
2. 进入 WordPress 后台的「外观 → 主题 → 安装主题 → 上传主题」。
3. 上传 ZIP、安装并启用。
4. 点击 WordPress 后台左侧的「手账主题设置」，进入独立设置中心。

如果通过服务器文件管理器安装，也可以把文件夹复制到 `wp-content/themes/cozy-journal-wordpress-theme/`，再到后台启用。

## 可调整内容

主题选项主要位于后台左侧的「手账主题设置」。这里提供类似专业主题面板的独立设置中心，带分区导航、顶部/底部保存按钮、分区重置、全部重置和设置备份恢复。原有「外观 → 自定义 → 手账主题设置」仍然保留，可用于实时预览。

- 初始设置：首页欢迎卡与日期开关、静态首页最新文章数量。
- 首页欢迎卡：小标签、标题、说明、按钮文字与链接。
- 颜色与字体：主色、点缀色、纸张色、卡片色、文字色、标题/正文字体以及卡片圆角。
- 文章与布局：双列拼贴或单列日记、侧栏、特色图片与摘要开关。
- 纸胶带与贴纸：装饰开关，以及花草、宅家、甜点、星月四套贴纸。
- 页脚小纸条：页脚寄语与年份/站点名开关。
- 备份与恢复：导出或导入 JSON 设置文件，以及安全恢复主题默认值。

站点名称、站点副标题和 Logo 仍在 WordPress 自带的「站点身份」区域设置。导航菜单在「外观 → 菜单」中分别分配到“主导航”和“页脚导航”。

## 推荐的首次设置

1. 在「设置 → 阅读」中选择“您的主页显示：您的最新文章”，即可直接使用主题首页；也可以选择一个静态页面，并在主题的“初始设置”中调整页面正文下方的最新文章数量。
2. 为文章设置特色图片，文章卡片会呈现为拍立得拼贴效果。
3. 在「外观 → 小工具」中给“手账侧栏”添加作者简介、搜索、分类、标签或近期文章。
4. 在「设置 → 固定链接」中使用文章名结构，让链接更清晰。

## 主题特性

- 响应式布局，适配桌面、平板和手机。
- 支持自定义 Logo、菜单、背景、特色图片、评论与小工具。
- 支持 Gutenberg 宽幅/全宽区块、编辑器样式和主题色板。
- 带文章、页面、归档、搜索、404、评论和无内容状态模板。
- 键盘焦点、跳转正文链接、导航 ARIA 属性和减少动态效果支持。
- 打印文章时自动隐藏导航、侧栏和装饰。
- 不加载远程资源，适合国内网络环境。
- 带独立后台主题设置中心，并与 WordPress 自定义器同步主题设置。
- 支持设置导出、导入、分区重置与全部重置。

## 文件结构

```text
cozy-journal-wordpress-theme/
├─ assets/css/              独立主题设置中心样式
├─ assets/js/               前台导航、自定义器和后台设置交互
├─ inc/                     自定义器、独立设置中心与模板标签
├─ template-parts/          文章卡片、正文和空状态
├─ 404.php                  404 页面
├─ archive.php              归档页
├─ comments.php             评论区
├─ footer.php               页脚
├─ front-page.php           首页
├─ functions.php            主题功能入口
├─ header.php               页头与导航
├─ index.php                默认文章列表
├─ page.php                 独立页面
├─ search.php               搜索结果
├─ searchform.php           搜索表单
├─ sidebar.php              小工具侧栏
├─ single.php               文章页
├─ style.css                主题信息与完整样式
├─ theme.json               区块编辑器配置
└─ CHANGELOG.md             版本更新记录
```
