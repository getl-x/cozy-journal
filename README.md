# Cozy Journal

Cozy Journal 是一款经典 WordPress 手账主题，以纸张、胶带、贴纸和卡片为主要视觉元素。主题不加载外部字体或装饰图片，核心展示与交互由 PHP、CSS、JavaScript 和字符图案完成。

- 版本：`1.6.1`
- 作者：`GetL-X`
- 来源：<https://github.com/getl-x/cozy-journal>
- 许可证：GNU GPL v2 or later

## 安装

1. 将 `cozy-journal-wordpress-theme` 文件夹压缩为 ZIP，或使用项目根目录的发布脚本生成安装包。
2. 在 WordPress 后台进入“外观 → 主题 → 安装主题 → 上传主题”。
3. 上传 ZIP，安装并启用 Cozy Journal。
4. 在后台左侧打开“Cozy Journal 设置”，检查内容、布局、外观、写作和隐私选项。

主题目录、Text Domain 和代码前缀继续使用原有兼容标识，升级不会因为公开名称中性化而丢失已有设置。

## 设置中心

v1.6.1 共提供 166 个设置，分为以下区域：

- 品牌与来源
- 初始设置
- 前台写作
- 全局样式
- 页头与导航
- 首页设置
- 文章列表
- 正文阅读
- 侧栏与页脚
- 纸张与装饰
- 搜索与提示文案

同一批设置也会注册到“外观 → 自定义 → Cozy Journal 设置”，两处修改都保存在 WordPress theme mods 中。

### 中性品牌

新安装默认使用：

- 设置中心显示名称：`Cozy Journal`
- 设置中心说明：`一个简洁灵活的 WordPress 手账主题`
- 设置中心标记：`CJ`

这些内容可以在“品牌与来源”中修改，只影响主题后台界面，不会更改 WordPress 站点标题。

页尾主题来源默认显示为 `✿ Theme Cozy Journal by GetL-X`。可以关闭整个来源行，或修改符号和前缀文字；`GetL-X` 始终链接到项目仓库。

### 主理人称呼

主题设置首页的问候名称按以下顺序决定：

1. 用户在“站点主理人名称”中保存的值；
2. 当前登录用户的 WordPress `display_name`；
3. WordPress 站点名称；
4. 中性称呼“站点主理人”。

升级不会主动填写或覆盖已经保存的主理人名称。

## 前台写作台

写作台默认路径是：

```text
/write/
```

可以在“Cozy Journal 设置 → 前台写作 → 写作页面路径”中修改。主题升级不会重置已有站点保存的路径。

写作台只允许已登录且具备相应文章权限的用户访问，并保留 WordPress nonce、文章权限、编辑锁、草稿自动保存和媒体上传检查。

为了减少截图或演示内容中的身份特征，新安装默认：

- 不显示当前用户头像；
- 不显示当前用户公开名称，改为中性“当前用户”；
- 编辑锁不显示协作者公开名称，改为“另一位用户”。

管理员可按站点需要分别开启这些显示项。

## 作者与评论隐私

新安装默认不显示文章卡片和正文页中的作者。即使开启作者显示，也默认只显示纯文字姓名，不链接作者归档；管理员可以单独开启作者归档链接。

评论区默认不显示评论者头像，也不会把评论者名称链接到其填写的个人网站。两项均可在后台设置中单独开启。

这些默认值只控制主题前台输出，不会删除或修改 WordPress 数据库中的用户、文章或评论资料。

## 设置备份与分享

后台“备份恢复”提供两种导出：

### 完整私有备份

包含全部主题设置，适合站点迁移和私人恢复。文件可能包含主理人称呼、写作路径、自定义 URL、版权文字和个性化文案，不适合直接公开。

文件名固定为版本化名称，不包含导出时间：

```text
cozy-journal-private-backup-v1.6.1.json
```

### 脱敏样式模板

只包含复选框、颜色、数值、范围和选择项，不包含自由文本、长文本、路径或 URL，适合分享主题布局与外观。

```text
cozy-journal-style-template-v1.6.1.json
```

两种 JSON 都保留 `theme`、`version`、`export_type` 和 `settings`，不写入本地导出时间。导入功能继续兼容旧版有效备份格式，并只接收当前主题已知的设置键。

## 发布包

正式发布 ZIP 包含主题运行文件和原创的 `screenshot.png`，不包含本地预览、备份或构建目录。ZIP 条目时间固定为中性时间，发布记录只保留版本和 SHA-256。

`screenshot.png` 由项目本地原创绘制，只使用几何图形、文字和主题自身配色，不包含第三方照片、插画或远程素材。
